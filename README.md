O jogo Escape-Room consiste em você desarmar uma bomba antes que ela exploda.  

Tudo começa na tela de início, onde você deverá apertar o botão de confirmação para ir para a escolha do modo.

Escrevendo "F" no monitor Serial você irá para a fase fácil, e escrevendo "D" irá para a fase difícil.


Na fase fácil, o jogador terá 2 desafios e 5 minutos para completar todos eles.

Na fase difícil, o jogador terá 3 desafios e 6 minutos para completar todos eles.

Em ambas as fases, o jogador terá 2 erros, no terceiro a bomba explodirá e o jogo acabará. Além disso, todas as instruções estarão no Monitor Serial.

Ganhando em qualquer um dos desafios, o jogador irá para a tela de vitória, e pressionando o botão de confirmação, irá voltar para a tela de início.

Ao errar pela terceira vez ou esgotar o tempo, o jogador irá para a tela de derrota, e pressionando o botão de confirmação, irá voltar para a tela de início.

O jogador poderá jogar quantas vezes quiser.



É importante saber que cada fase terá penalidades no tempo para quem errar: 40 segundos por erro na fase fácil e 90 segundos na difícil
